# Blender asset scripts

The models in `public/models` are generated by these scripts inside a running Blender (5.1+)
with the **Blender Lab MCP add-on** listening on `localhost:9876`:

```sh
python3 scripts/blender/bl.py scripts/blender/b_transmitter.py   # Sender Gaisberg (100 m mast) + neighbour mast
python3 scripts/blender/bl.py scripts/blender/b_props.py         # bench, guidepost, bus stop, crosses, board, snow fence, power pole, firewood
python3 scripts/blender/bl.py scripts/blender/b_life.py          # paraglider, cars, motorbike (and a first cow)
python3 scripts/blender/bl.py scripts/blender/b_cow.py           # Pinzgauer cow (replaces the first one)
python3 scripts/blender/bl.py scripts/blender/b_rider.py         # road bike, wheel, crank and rider body parts → rider.glb
python3 scripts/blender/bl.py scripts/blender/b_rock.py          # Poly Haven rocks decimated to ~700 tris (needs research/gaisberg/assets)
```

`bhelp.py` holds the shared helpers (materials, tube/box mesh builder, GLB export, EEVEE preview).
Rider parts are authored in the three.js rider frame (+Z forward, +Y up) and converted with `T()`.
